C · Hive Terminal, at real phone size

Each frame is 360 px wide, the GDD's minimum phone width. Text is 13–15 px monospace: what a phone would actually show, not a scaled-down preview. That gives about 38 characters per line, so every ASCII drawing is built to fit inside 36.

No emoji: resources use 4-letter labels, because emoji break the monospace grid. Big colonies: above about 100 ants, each character stands for a group of ants, shaded ░▒▓█ by how full it is (see the late-game frame). Phases change the phosphor color. The scanlines and glow are optional and would be switched off by reduced motion.
